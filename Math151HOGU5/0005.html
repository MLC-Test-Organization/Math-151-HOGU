    2.

    The chain rule states that \([f(g(x))]' = f'(g(x))g'(x)\text{.}\) That is, that the derivative of a composition of functions is "the derivative of the outside function \(f(x)\text{,}\) with the inside function \(g(x)\) plugged in, times the derivative of the inside function \(g(x)\)". Identify the outside function \(f(x)\) and the inside function \(g(x)\) for each of the following expressions.
    🔗
    (a)
    \(h(x)=(3-x^2)^7\)
    🔗
    Answer.
    \(f(x)=x^7\text{,}\) \(g(x)=3-x^2\)
    🔗
    🔗
    🔗
    (b)
    \(h(x)=e^{\frac{1}{x^2-1}}\)
    🔗
    Answer.
    \(f(x)=e^x\text{,}\) \(g(x)=\dfrac{1}{x^2-1}\)
    🔗
    🔗
    🔗
    (c)
    \(h(x)=\sqrt{2x+5}\)
    🔗
    Answer.
    \(f(x)=\sqrt{x}\text{,}\) \(g(x)=2x+5\)
    🔗
    🔗
    🔗
    (d)
    \(h(x)=\sin^2(x)\)
    🔗
    Answer.
    \(f(x)=x^2\text{,}\) \(g(x)=\sin(x)\)
    🔗
    🔗
    🔗
    (e)
    \(h(x)=\csc(\sqrt{-x})\)
    🔗
    Answer.
    \(f(x)=\csc(x)\text{,}\) \(g_1(x)=\sqrt{x}\text{,}\) \(g_2(x)=-x\)
    🔗
    🔗
    🔗
    (f)
    \(h(x)=\tan^3((x-1)^5)\)
    🔗
    Answer.
    \(f(x)=x^3\text{,}\) \(g_1(x)=\tan(x)\text{,}\) \(g_2(x)=x^5\text{,}\) \(g_3(x)=x-1\)

    Find the derivatives of the following functions using derivative rules.
    🔗
    (a)
    \(f(x)=x^3(1+x)\)
    🔗
    Answer.
    \(f'(x)=3x^2(1+x)+x^3\)
    🔗
    🔗
    🔗
    (b)
    \(f(x)=(3x^2+5x)(5+2^x)\)
    🔗
    Answer.
    \(f'(x)=(6x+5)(5+2^x)+(3x^2+5x)(2^x\ln(2))\)
    🔗
    🔗
    🔗
    (c)
    \(f(x)=\dfrac{1}{x^2}\)
    🔗
    Answer.
    \(f'(x)=\dfrac{-2}{x^3}\)

    🔗
    🔗
    (d)
    \(f(x)=\dfrac{x^3+1}{x^2-4}\)
    🔗
    Answer.
    \(f'(x)=\dfrac{(x^2-4)(3x^2)-(x^3+1)(2x)}{(x^2-4)^2}\)
    🔗
    🔗
    🔗

    \(f(x)=\dfrac{(x^3-2x+1)(3x-5)}{x^2+1}\)

    Answer.

    3.

    Find the derivatives of the following functions using derivative rules.
    🔗
    (a)
    \(f(x)=x+\sin(x)\)
    🔗
    Answer.
    \(f'(x)=1+\cos(x)\)
    🔗
    🔗
    🔗
    (b)
    \(f(x)=x\cos(x)+x^2\tan(x)\)
    🔗

    \(f'(x)=\cos(x)-x\sin(x)+2x\tan(x)+x^2\sec^2(x)\)
    🔗
    🔗
    🔗
    (c)
    \(f(x)=x^2\csc(x)\)
    🔗
    Answer.
    \(f'(x)=2x\csc(x)-x^2\csc(x)\cot(x)\)
    🔗
    🔗
    🔗
    (d)
    \(f(x)=\dfrac{(x^3+1)\sec(x)}{(x^2+1)\cos(x)}\)
    🔗
    Answer.
    \(f'(x)=\dfrac{(x^2+1)\cos(x)((3x^2)\sec(x)+(x^3+1)\sec(x)\tan(x))-(x^3+1)\sec(x)((2x)\cos(x)-(x^2+1)\sin(x))}{((x^2+1)\cos(x))^2}\)
    🔗
    🔗
    🔗
    (e)
    \(f(x)=\dfrac{\cot(x)}{x^2+1}\)
    🔗
    Answer.
    \(f'(x)=\dfrac{-(x^2+1)\csc^2(x)-\cot(x)(2x)}{(x^2+1)^2}\)
